# Logos des modes de paiement

Déposez ici les trois logos, en PNG, avec **exactement** ces noms de fichier :

| Fichier            | Mode de paiement       |
|--------------------|------------------------|
| `masrvi.png`       | Mobile Money Masrvi    |
| `sedad.png`        | Mobile Money Sedad     |
| `bakily.png`       | Mobile Money Bakily    |

Les noms sont en minuscules, sans accent et sans espace : c'est le code qui va
les chercher sous ces noms précis.

## Format conseillé

- **PNG à fond transparent** — le logo apparaît sur fond blanc comme sur fond
  coloré, notamment sur les reçus imprimés.
- **Carré, 128 × 128 pixels** suffit largement : les logos s'affichent en petit
  (16 à 24 pixels). Plus grand n'apporte rien et alourdit chaque page.
- **Moins de 30 Ko** par fichier.

## Tant qu'un fichier est absent

Rien ne casse : le logo manquant est simplement ignoré et le nom du mode de
paiement s'affiche seul, comme aujourd'hui. Vous pouvez donc les ajouter un par
un, sans rien attendre.

Espèces et Virement bancaire n'ont pas de logo : ce ne sont pas des marques.
